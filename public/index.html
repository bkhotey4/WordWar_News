SYSTEM NOTICES

系統已知限制與誠信須知

運作限制
  • 自動中文研究執行器尚未設定；來源採集不等於自動完成研究分析。
  • 目前原文自動採集主要是烏克蘭軍方與軍方媒體；來源數量不等於獨立佐證數。外部評估需另外查閱並匯入。
  • 已有附產品來源的區域影像裁切與不同日期比對；雲遮、覆蓋差異與像素對位尚未用於自動戰損判讀。
  • 未核實新聞保留待查、不發送已核實特報；台海 P95 僅供觀察，公開航空異常通知仍需查核。不能宣稱能預測戰爭。
  • 台海觀測、事件版本與影像紀錄採 SQLite 交易；舊研究稿 JSON 仍須避免跨程序同時發布。
  • Discord 已接受訊息後、成功紀錄落盤前若程序崩潰，仍可能重送；目前無法保證嚴格只送一次。
  • 對引用的格式與時效驗證不會自動證明段落語意真的受到來源支持，仍需研究者比對原文。
  • 舊專題與圖卡產生器尚保留歷史內容，但沒有接回有效報導流程。要恢復功能必須改為讀取有來源的資料。

來源中斷、時間過期或原始連結缺失時，以「未取得」呈現；沒有資料不代表沒有事件。
