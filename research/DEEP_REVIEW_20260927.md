## 修正的邏輯缺陷

| 問題 | 修正 |
|---|---|
| 兩份自行標記 Tier1 的資料直接等同已證實 | 保存来源但不自動認定證實；衝突需覆核 |
| 未標記警報被當成誤報，時間接近當成命中 | 僅採明確覆核與事件配對；未標记為未知，完整資料集未確認則召回率未知 |
| 整片影像雲量被當成裁切區可判讀 | 整片品質與局部可見度分開，未判讀不給可讀百分比 |
| NOTAM 取消／替代仍出現在有效預警 | 排除取消與被替代公告；官方採集占位程式仍不宣稱已接通 |
| 同一衛星相隔數小時熱點 FRP 相加 | 要求同衛星且相隔不超過30分鐘；快取版本3排除舊群集 |
| 已發布新稿引用舊背景被來源清理刪除 | 保留有效稿引用的背景來源；被新版取代稿停止有效展示 |
| 研究推播只送空狀態或重複稿 | 僅送有效報導，SQLite 以報導版本和收件人去重及失敗重試 |
| 測試寫入正式證據／偏好檔 | 測試改用暫存檔，既有假測試資料移至 quarantine |
| 健康狀態寫死研究執行器未設定 | 讀本機实际 automation.toml；區分排程設定與成功執行 |
